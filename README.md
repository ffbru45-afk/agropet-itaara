# AgroPet Itaara

Catálogo digital responsivo com carrinho de consulta via WhatsApp.

## Executar

```bash
npm install
npm run dev
```

## Publicar

Importe este repositório na Vercel. Framework: Vite; build: `npm run build`; saída: `dist`.

## Configuração necessária

Em `src/App.jsx`, altere `WHATSAPP` para o número oficial com DDI e DDD, apenas dígitos. O botão de envio permanece desativado com aviso até essa configuração.

Produtos são exemplos de categorias, sem preços ou estoque real. Atualize catálogo e imagens antes de divulgar como oferta da loja.
